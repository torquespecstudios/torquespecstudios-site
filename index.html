About the studio

Games and apps built to spec

Torque Spec Studios is an independent game and app studio based in Washington State. The name comes from engineering: a torque spec is the exact value a part has to be built to. Not close, not good enough, exactly right. That's the standard we hold every game and app to.

Swervy is the first. More games and apps are on the way.
